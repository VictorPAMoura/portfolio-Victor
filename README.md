## Descrição do projeto

Portfólio acadêmico criado para apresentar meu perfil, meus projetos e minhas habilidades em desenvolvimento web e testes de software (QA).

## Tecnologias utilizadas

- HTML5 para estruturar o conteúdo.
- CSS3 para cores, layout e animações.
- Bootstrap 5.3.3 para a navegação responsiva, os cartões e os botões.

## Funcionamento do projeto

O site possui um menu de navegação que direciona o visitante para as seções Início, Perfil, Projetos, Habilidades e Contato. A seção de Projetos apresenta exemplos de atividades acadêmicas. A página adapta o layout para telas menores por meio do Bootstrap.

## Recurso novo adicionado

Foram incluídos **efeitos de hover nos cartões dos projetos** e uma **nova seção de Habilidades**.

## Como os recursos foram implementados

O efeito de hover foi implementado com CSS, usando `.card:hover`, `transform: translateY(-9px)`, `box-shadow` e `transition`. Quando o visitante passa o mouse sobre um cartão, ele se desloca suavemente para cima e recebe uma sombra e uma borda destacada. A seção Habilidades foi construída com HTML e estilizada com classes CSS personalizadas.

## Como executar

Abra o arquivo `index.html` em um navegador com conexão à internet para carregar o Bootstrap via CDN.
